## 💡 Sobre o Projeto

O **Gprice** é um sistema inteligente de precificação para marketplaces que calcula automaticamente o preço ideal de produtos considerando:

- Impostos por estado (ICMS)  
- Substituição Tributária (ST)  
- Regime tributário  
- Taxas de marketplace  
- Margem de lucro  

👉 Ideal para vendedores que querem maximizar lucro no Brasil.

✅ Filtro por região  
✅ Tema Dark/Light  
✅ Interface moderna e responsiva

## 🧠 Diferencial

Enquanto ferramentas comuns calculam preço fixo, o Gprice mostra:

📊 Onde vender melhor  
📉 Onde evitar prejuízo  
💰 Margem real por estado

## 🧮 Como funciona

O sistema aplica a fórmula:
Preço = (Custo + despesas) / (1 - impostos - taxas)

Com base em:

- ICMS estadual  
- Comissão marketplace  
- Regime tributário  
- ST e redução de base
